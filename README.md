# 🌑 구현기능

### ✅ 필수 기능

- Routing : 리액트 라우터 돔을 활용한 페이지 간 이동
- 포켓몬 리스트 추가, 삭제 버튼
- Query 파라미터를 이용한 상세페이지 이동 (뒤로가기 버튼 포함)
- grid를 활용한 반응형 카드

  <br/>

### ✴️ 도전 기능

- UI 라이브러리 적용 (SweetAlert2)
- 로컬스토리지 저장/삭제 기능
- 디테일 페이지에 추가/삭제 버튼 구현
  <br/>

# ✔️ 추가기능

- 유효성 검사

1. 이미 추가한 포켓몬의 경우 알림
2. 추가된 포켓몬이 6마리 이상일 경우 알림
